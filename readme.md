# Korsa
A Multi-tools written in lua fork from kls

- **Warning** : This is written for educational purpose and not for and production uses

## Project file structure  :

```
  ./Korsa (root)
     |
     |_ kls.lua
     |
     |_ prettytext.lua
     |
     |_ colord.lua
     |
     |_ config.lua --(auto generated)
```

## Binary Compiling

- This can be done using srlua but luaot is also a great alternative
